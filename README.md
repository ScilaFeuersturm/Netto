# Inariko

App de finanzas personales para Android e iOS: facturas y vencimientos, ingresos en varias monedas
(PYG, ARS, USD), modelos de ahorro, reportes y escaneo de facturas con OCR.

| Carpeta | Contenido |
| --- | --- |
| [`mobile/`](mobile/) | App Expo (React Native) para Android e iOS. Ver su README para correrla. |
| [`supabase/`](supabase/) | Backend: esquema de la base, políticas de seguridad, funciones y tests. |

La versión anterior, nativa de Android en Kotlin, quedó en el historial de git
(commit `6f1f9d9` y anteriores).
